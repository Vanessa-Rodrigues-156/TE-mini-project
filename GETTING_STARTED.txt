❓ FAQ

Q: Which should I run - notebook or script?
A: For learning: notebook (interactive cells)
   For production: script (faster, automated)

Q: What if training is slow?
A: Sample your data: df = df.sample(frac=0.5)
   Or use fewer trees: n_estimators=50

Q: What's SMOTE?
A: Handles imbalanced data by creating synthetic samples
   Usually improves model accuracy by 5-10%

Q: Can I use text from case descriptions?
A: Not in Step 7 (structured only)
   Step 8 (coming soon) will add LegalBERT text model

Q: How do I make predictions on new cases?
A: Load the model and use predict_adr_suitability() function
   See Step 7 notebook for example code
